# Xiwen (Echo) Yan — Bio

Personal homepage: https://bio.xiwenyan.top/ · Portfolio: https://portfolio.xiwenyan.top/

Built with Jekyll on GitHub Pages using the [Minimal Light](https://github.com/yaoyao-liu/minimal-light) theme (see `LICENSE`).

## Edit

- `index.md`: page content
- `_config.yml`: name, links, SEO description, plugins (sitemap, SEO tags)
- `_layouts/homepage.html`: page structure
- `assets/css/style.scss`: styles (the playful layer is at the end)
- `assets/files/resume.pdf`: résumé

Pushing to `main` publishes the site.
